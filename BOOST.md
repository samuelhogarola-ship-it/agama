# BOOST

## Pack Recomendado

**Pack Engagement + Optimizacion de Conversion**

La base tecnica, velocidad y rendimiento del sitio ya estan optimizados.  
La siguiente fase recomendada es convertir la web en una herramienta comercial mas efectiva: que guie mejor al usuario, resuelva mejor sus dudas y aumente el numero de contactos cualificados.

---

## Objetivo

Mejorar la conversion de la web con cambios estrategicos no contemplados en la fase actual, centrados en:

- orientar mejor al usuario
- facilitar la busqueda de productos
- reducir friccion en la navegacion
- aumentar consultas, contactos y solicitudes de presupuesto
- convertir la web en una herramienta mas util para ventas

---

## Que Incluye

### 1. Entrenamiento y mejora del chatbot

- afinado del chatbot segun productos, catalogo y necesidades reales del cliente
- respuestas mas utiles segun tipo de usuario
- mejor enfoque comercial y de soporte
- ajuste de prompts y flujos conversacionales

### 2. Optimizacion del recorrido del usuario

- revision del journey del visitante dentro de la web
- mejora de puntos de entrada, navegacion y llamadas a la accion
- reduccion de pasos innecesarios
- mejoras orientadas a facilitar el contacto y la conversion

### 3. Reorganizacion del catalogo

- mejor clasificacion interna de `Masterbatch`, `Pigmentos` y `Aditivos`
- posible creacion de categorias, subcategorias o agrupaciones mas utiles
- mejora de lectura comercial del catalogo
- estructura pensada para que el cliente encuentre antes lo que busca

### 4. Buscador mas inteligente y guiado

- buscador con enfoque mas util para negocio
- ayuda al usuario a encontrar productos aunque no conozca exactamente el nombre tecnico
- posibilidad de guiado por necesidad, aplicacion o referencia
- mejora de experiencia de busqueda y descubrimiento

### 5. Localizador de filiales por codigo postal

- integracion de un localizador dentro de `/filiales/`
- el usuario introduce su codigo postal y la web muestra la tienda mas cercana
- reduce friccion para clientes que no saben que sucursal les conviene
- mejora la utilidad comercial de la seccion de filiales
- puede ayudar a aumentar contactos y visitas a la sucursal correcta

### 6. Microcopy y mensajes orientados a conversion

- inclusion de mensajes mas estrategicos dentro del sitio
- preguntas guiadas para ayudar al usuario a avanzar
- mejora de textos de apoyo y CTA

Ejemplos:

- `Que necesitas hoy?`
- `Buscas algo para tu negocio?`
- `Tienes un codigo o referencia en mente?`
- `Necesitas ayuda para encontrar el material adecuado?`
- `Quieres que te recomendemos una opcion segun tu uso?`

## Oportunidad Detectada: FAQ

Actualmente el FAQ **si existe** en `/faqs`, pero no esta suficientemente aprovechado como seccion visible y util dentro del sitio.

Ademas, parte de ese contenido tambien aparece incrustado dentro de `filiales`, pero ahora mismo:

- no tiene suficiente visibilidad
- no esta bien integrado en la estructura principal del sitio
- no esta planteado con suficiente fuerza como recurso util y claro
- falta enlace y jerarquia para que el usuario llegue ahi
- no se esta aprovechando bien a nivel de indexacion y descubrimiento
- al estar escondido, casi nadie lo consulta

En la practica, esto significa que ya existe contenido con valor comercial y de soporte, pero hoy esta **desaprovechado**.
No esta ayudando a resolver dudas, no esta reduciendo friccion y no esta empujando conversion como podria hacerlo.

### Mejora recomendada

- optimizar el FAQ existente en `/faqs`
- dar mas visibilidad al contenido ya creado
- incorporarlo de forma visible dentro de `filiales`
- crear un acceso mas claro desde la zona donde ya tiene sentido para el usuario
- reforzar su presencia dentro del recorrido comercial real del sitio
- usar FAQ para resolver dudas frecuentes antes de que el usuario abandone o tenga que preguntar

**Importante:** la propuesta no pasa por restaurar un enlace general fuera del producto actual, sino por **aprovechar mejor el contenido dentro de `filiales`**, donde hoy ya existe contexto y donde puede aportar mas valor inmediato.

### Valor de negocio

- reduce friccion
- mejora la experiencia del usuario
- ahorra preguntas repetidas
- refuerza confianza
- ayuda a convertir mejor
- activa un recurso ya existente que ahora mismo no esta rindiendo

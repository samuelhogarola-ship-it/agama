# Web References

Referencias activas para la landing de `eventos` y para la direccion visual general de AGAMA.

## Referencias principales

### 1. Clueso

URL: [https://www.clueso.de/](https://www.clueso.de/)

Que nos interesa de esta referencia:

- Hero muy dominante y limpio.
- Sensacion editorial, no corporativa.
- Imagen principal anclada mientras el contenido sube por encima.
- Transicion por scroll donde el hero pierde fuerza visual de forma elegante.
- Tipografia muy grande, marcada y con mucho aire.

### 2. Verdu 1946

URL: [https://verdu1946.com/](https://verdu1946.com/)

Nota:

- Esta referencia la añadimos por preferencia del cliente.
- El cliente la percibe como cercana a un lenguaje tipo McDonald: muy directa, comercial, reconocible y con impacto visual inmediato.

Que nos interesa de esta referencia:

- Composiciones muy claras.
- Imagenes limpias y reconocibles.
- Grafica comercial fuerte.
- Sensacion popular-premium, viva y accesible.
- Colores intensos y memorables sin perder orden.

## Direccion visual acordada

Si queremos que este proyecto quede de estrellas, la mezcla correcta es:

- Imagen limpia de AGAMA arriba, muy protagonista.
- Hero fijado durante el scroll.
- La imagen se mantiene visible y se transparenta al bajar.
- Letras grandes, muy marcadas y minimalistas.
- Colores vivos, pero con composicion limpia.
- Sensacion editorial + comercial, no web industrial clasica.
- Ritmo visual fuerte en el primer pantallazo y continuidad elegante debajo.

## Regla de decision para esta landing

Cuando haya dudas de estilo, priorizar en este orden:

1. Claridad visual inmediata.
2. Hero potente con imagen AGAMA.
3. Scroll con fijado/transparencia tipo Clueso.
4. Impacto comercial limpio tipo Verdu 1946.
5. Tipografia grande, simple y con color vivo.
